## 3. Current feature list (what the app does today)

**Homepage (`/`, "今日觀察")** — decision-support cockpit, explicitly does NOT predict direction (8y walk-forward found no systematic 1-3d directional edge — see `cockpit.py` docstring / scoreboard). Shows per-symbol:
- Price + key levels (SMA20/50, N-day high/low), breakout/pullback posture grouping.
- News tie-in (sentiment, novelty, priced-in estimate) with plain-language glossary tooltips.
- IV, dollar volume, next earnings date.
- Volume-vs-average and sector-linkage (idiosyncratic vs beta move) badges.
- Sell-put income idea, backtest-gated (green/red), collapsed by default.
- 📋 今日盤前摘要 (pre-market briefing): macro/news narrative, sector rotation, 選擇權環境/今日焦點/最近財報 tiles.
- 🎯 模型方向預測戰績: transparent historical hit-rate of the direction model.
- 📉 今日盤後總結 (post-market wrap): headline + narrative + top movers with honest driver attribution.

**News Radar (`/news`)** — full news feed, freshness strip ("最後更新 X / 上次抓取 N則 / 近24h N則" — currently showing the stale numbers described in §2), "new since last visit" indicator, per-item detail page.

**Arena (`/arena`)** — 6 simulated trader "philosophies" (Chartist/Analyst/Contrarian/Macro/etc.), each running a $25k paper options account, purely for comparing strategy logic (never real orders). Leaderboard (realized return, win rates, hit rate), Live Board (all traders' trade tape, now with the 3-state colour system), per-trader profile pages, cross-trader divergence radar.

**Watchlist**: 31 symbols — 22 core (semiconductor, big tech, financials, energy) + 9 secondary. See `CLAUDE.md` §3 for the intended structure.

**Backend**: FastAPI, all routes under `/api/*`, entirely read-only/GET, documented endpoint-by-endpoint in `src/stockmoney/api/main.py`.

**Data-integrity layer** (new this session): `src/stockmoney/data/validation.py` + `strike_ladder.py` + `integrity_fixes.py` — use these for any future data-generating code.
