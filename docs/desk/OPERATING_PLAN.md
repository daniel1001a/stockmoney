# Trading Desk 營運計畫(v2 主線)

> 2026-10-09 建立。取代舊系統「1-3 天選擇權方向預測」主線。舊程式碼保留,不刪。

## 1. 先講現實

**舊專案已經用數據證明的事**(2026-07 六個實驗,全部 walk-forward、扣成本、對照 baseline):
- 1-3 天選擇權擇時:沒有任何方法打贏「單純持股」。方向模型、新聞情緒、橫向動能,全部輸。
- 唯一可靠的報酬來源:股票本身的長期上漲(beta)+ 小幅的賣方波動率溢酬。
- 結論:**短天期 + 選擇權 = 每天付 theta 和價差的稅,邊際太薄。**

**新主線的回測**(股票、持有數週、順勢,2015-06 到 2026-10,規則事前固定、沒調參):

| | 年化 | 最大回撤 | Sharpe | 勝率 | 獲利因子 |
|---|---|---|---|---|---|
| 三策略合併 | 14.7% | -19.8% | 1.03 | 39% | 1.55 |
| SPY 買進持有 | 14.0% | -33.7% | 0.83 | - | - |

- 報酬和大盤差不多,但回撤少約四成,平均只用七成資金。這是順勢策略的典型樣貌:**價值在「避開大跌」,不是「每天贏」**。
- 回測有倖存者偏差(清單是今天的大型股),真實表現會比較差。紙上交易月才是誠實的測試。
- **勝率只有 39% 是正常的**。順勢靠「小賠多次、大賺少次」。目標是期望值(每筆平均報酬 × 次數),不是勝率。刻意拉高勝率(例如太早停利)通常會殺掉期望值。

**一個月紙上交易能證明什麼**:大約 20-60 筆交易,統計上不足以證明策略有 edge。這個月真正要驗證的是:
1. 流程跑得順(每天資料、訊號、成交、停損都正確)
2. 紙上結果和回測行為一致(沒有實作 bug)
3. 你的人工判斷是加分還是扣分(desk 帳戶 vs combined 帳戶)
4. 你每天花的時間可持續

## 3. 系統架構:三層順勢確認

```
第一層 大盤     SPY vs 50/200 日線 + 市場寬度  -> 多頭順風 / 中性 / 空頭逆風 -> 決定總曝險上限(100% / 50% / 0%)
第二層 資金流向 12 個板塊 ETF 的 63 日相對強度    -> 領漲板塊(前 4 且贏 SPY 且站上 50 日線)
第三層 個股     多頭排列 + 相對強度 + 觸發條件    -> 進場訊號(附停損、論點、失效條件)
```

三個策略(都只做多,空頭時空手 = 順勢):
- **強勢突破** `breakout`:領漲板塊裡,放量創 55 日新高
- **多頭回檔** `pullback`:相對強勢股回測 20 日線後轉強
- **動能輪動** `rotation`:每月底持有動能最強的 5 檔

風控(機器強制執行,人不能關):每筆最多虧帳戶 0.75%、單檔最多 20%、最多 8 檔、同板塊最多 2 檔、移動停損(最高收盤 - 3 ATR)、跌破 50 日線出場。

帳戶(各 25,000 USD 紙上資金):
- `breakout` / `pullback` / `rotation` / `combined`:全自動,機器基準線
- `desk`:同樣的訊號,每筆進場都要你核准。**desk 減 combined = 你的判斷值多少錢**

## 4. 人機分工

切分原則:**機器做「規則明確、需要紀律、需要記憶」的事;人做「需要脈絡、需要對規則本身負責」的事;AI 做「需要讀大量文字、需要整理」的事。**

| 工作 | 誰做 | 為什麼 |
|---|---|---|
| 抓資料、算指標、掃描 92 檔 | 機器 | 人做會漏、會累 |
| 停損、部位大小、曝險上限 | 機器,人不能關 | 人最容易在這裡破功(凹單、加碼攤平)。紀律交給機器 |
| 判斷大盤順風逆風 | 機器(規則)+ 人(覆寫的理由寫進日誌) | 規則判斷穩定但慢;人能看到政策、地緣政治等規則看不到的東西 |
| 核准 / 拒絕 / 放大縮小單筆部位 | 人 | 機器不知道「這家公司下週有官司判決」。但每次都要寫理由,讓之後能算你是否加分 |
| 讀新聞、確認訊號沒有被消息推翻 | AI 輔助(下一步建),人決定 | LLM 擅長讀文字、找風險;不擅長預測價格(舊實驗已證明) |
| 每日覆盤:機器摘要 | 機器 | 自動產生 |
| 每日覆盤:「我學到什麼」 | 人 | 這是累積經驗的唯一方式,機器替代不了 |
| 從日誌找規律、提出新策略假設 | AI + 人 | AI 能讀完一個月的日誌找重複模式;人判斷是否合理 |
| 驗證新策略 | 機器(回測 + 紙上影子帳戶) | 防止「感覺很對」的策略直接上線 |
| 改參數、加策略、決定上真錢 | 人 | 對系統本身負責的永遠是人 |

**機器的極限**(要知道,才不會過度相信):
- 只看價格與成交量,看不到「為什麼」。突發消息(併購、調查、政策)會讓技術訊號瞬間失效。
- 規則是從歷史歸納的。市場結構改變時(例如 2020 年 3 月),規則會慢半拍。
- 回測永遠比實盤好看(倖存者偏差、成交價理想化)。
- 不會「感覺不對勁」。

**人的極限**:
- 會在虧損時恐慌、獲利時貪心、連續贏之後過度自信。
- 會記住贏的、忘記輸的。
- 會在同一段歷史上反覆調參數,把雜訊當規律(過擬合)。

系統的設計就是讓兩邊互補:**人提供脈絡和判斷,機器提供紀律和記憶,所有人為決定都被記錄、之後被機器檢驗。**

## 5. 每日 / 每週 / 每月節奏

**每天盤後(美東 16:30 後,約 15-20 分鐘)**
1. 跑 `scripts/desk_daily.py`(之後排程自動跑)
2. 開 console「今日決策」:看大盤、資金流向、新訊號
3. 每筆待審核單:看四層證據(標 [注意] 的有某層不成立),核准 / 拒絕 / 調倍數,寫理由
4. 「覆盤日誌」:寫一兩句「市場判斷」和「學到什麼」

**每週末(約 30-45 分鐘)**
1. 看「績效」:desk vs combined vs SPY
2. 翻本週日誌,找重複出現的想法 -> 寫成可驗證的假設
3. 在「策略實驗室」回測假設;有理由、改善明顯才套用,而且寫理由

**每月底**
1. 檢討:每個策略的期望值、最大回撤、和回測是否一致
2. 你拒絕的訊號後來怎麼了?(拒絕得對 = 加分)
3. 決定下個月:哪個策略加碼、哪個停用、要不要加新策略

## 6. 怎麼正確地「提高勝率」

新策略或新規則一律走這條路,不能跳步:

```
日誌中的觀察 -> 寫成明確規則 -> 回測(要贏過 SPY 和現有策略,看信賴區間)-> 紙上影子帳戶跑至少 1 個月 -> 才進主帳戶
```

紀律:
- 一次只改一個東西,否則不知道是哪個改動有效
- 改動要有事前理由(「我認為 X 因為 Y」),不是「試試看哪個數字回測最好」
- 回測改善小於雜訊(信賴區間重疊)就不改
- 參數改動全部記錄在 `param_changes`,永遠可追溯

## 7. 路線圖

**第 1 週(現在)**:系統上線,每天跑、每天審核。重點是熟悉流程、抓 bug。

**第 2-4 週**:
- 排程自動化(每天盤後自動跑,不用手動)
- AI 訊號審查:每個新訊號由 Claude 讀近期新聞與財報資訊,標出「消息面風險」寫進 `signals.ai_review`,在審核畫面顯示。它只能建議否決,不能產生訊號
- 每週 AI 覆盤:讀一週日誌 + 交易紀錄,整理出規律與新假設

**一個月後的決策閘門**(你決定):
- 紙上結果和回測一致嗎?有沒有實作問題?
- desk 贏 combined 嗎?(你的判斷有沒有加分)
- 要不要用真錢?用多少?建議:先用小部分資金(例如 20%)照系統下單,手動在券商操作
- **自動下單是另一個獨立決定**。目前 CLAUDE.md 的硬邊界是「系統永不下單」。要改,需要你明確決定並修改規格,而且應該先經過至少一個月的真錢手動執行

**之後可以擴充**:
- 選擇權:等股票訊號證明有效後,把高信心訊號轉成選擇權表達(買價差,而不是裸買 call),舊專案的定價引擎可重用
- 放空 / 反向 ETF:空頭時的順勢
- 更大的股票池、板塊輪動更細
