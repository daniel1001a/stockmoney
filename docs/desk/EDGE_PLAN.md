# Edge 計劃:先證明會賺錢,再求穩定提高(2026-10-10)

> 依據:`research/desk_audit/audit.py` 的稽核(結果在 `research/desk_audit/results/`)。資料到 2026-10-09,回測期 2015-06 起。
> 三個原則:**順勢而為、不斷學習、消息為王**,外加**穩定優先**。

## 0. 一句話結論

這套系統**有一些真的 edge,但目前被出場規則吃掉了**:
- 進場訊號打贏同一份清單裡的隨機進場(年化勝過 99% 的隨機組),所以「選什麼、什麼時候買」有價值。
- 但整本書(13.0%)輸給「同一份清單、同樣曝險的等權持有」(16.2%),也輸給 SPY(14.0%)。原因主要在出場:72% 的交易被停損出場,這些交易平均只賺 0.9%;其他方式出場的交易平均賺 5.1%。
- 最近兩年明顯退化:2024 年 +3.1%(SPY +24.9%),2025 年 +2.8%(SPY +17.7%)。
- 拿掉事後看最強的 10 檔股票,年化從 13.0% 掉到 7.9%,倖存者偏差很重。

所以**現在還不能說它會賺錢**。紙上交易期的第一個任務是修好出場、建立對照組,讓「有沒有 edge」能被誠實地回答。

## 1. 稽核結果

### 1.1 和對照組比(2015-06 到 2026-10)

| | 年化 | 最大回撤 | Sharpe | 正報酬月份 |
|---|---|---|---|---|
| 三策略合併(現行) | 13.0% | -19.9% | 0.93 | 58% |
| SPY 買進持有 | 14.0% | -33.7% | 0.83 | 70% |
| SPY × 大盤濾網 | 8.4% | -21.2% | 0.75 | |
| 清單等權持有 | 23.4% | -34.4% | 1.20 | |
| 清單等權 × 大盤濾網 | 14.9% | -21.8% | 1.17 | 65% |
| 清單等權 × 固定 69% 曝險 | 16.2% | -24.8% | 1.20 | |

解讀:
- 大盤濾網確實能降低回撤(-34% 降到 -22%),「順勢」在大盤層有用。
- 但在同樣的回撤水準下,現行選股與出場打不贏「濾網 + 整份清單等權」。也就是說,**個股層目前是減分**。

### 1.2 隨機進場對照(每組 120 次)

隨機進場用同一份清單、同樣的停損、出場、部位大小和大盤濾網,只把「選哪檔、哪天買」換成隨機。這個對照組和現行策略吃到同樣的倖存者偏差,所以比較公平。

| | 年化中位數 | Sharpe 中位數 | 現行策略贏過幾 % 的隨機組 |
|---|---|---|---|
| 完全隨機 | 6.9% | 0.73 | 年化 100%,Sharpe 83% |
| 隨機,但只選多頭排列的股票 | 8.2% | 0.80 | 年化 99%,Sharpe 81% |

解讀:
- 進場訊號有價值:報酬明顯高於隨機。
- 但風險調整後只贏 81-83% 的隨機組,還不到 95% 的顯著水準。
- 隨機組的曝險有 58-64%,但年化只有 7-8%;同樣曝險的等權持有卻有 16%。**差距來自交易框架本身,也就是太常被洗出場。**

### 1.3 其他檢查

- **成本**:滑價從每邊 5 bps 提高到 15 bps,結果幾乎不變;提高到 30 bps,年化 11.5%。對成本不敏感,這是好事。
- **參數鄰近值**:結果對移動停損寬度最敏感(2.5 ATR:11.0%,3.0:13.0%,3.5:18.0%),其他參數變動都在 ±2% 內。
- **移動停損拆兩段驗證**:

| 移動停損 | 2015-06 到 2020 | 2021 到 2026-10 |
|---|---|---|
| 3.0 ATR(現行) | 18.0% / Sharpe 1.35 | 8.5% / 0.61 |
| 3.5 ATR | 22.6% / 1.59 | 13.9% / 0.92 |
| 4.0 ATR | 20.0% / 1.47 | 11.8% / 0.80 |
| 5.0 ATR | 17.2% / 1.31 | 10.3% / 0.71 |

  3.5 到 4.0 在兩段都比現行好,方向一致。但「3.5 最好」是看過結果才知道的,要當成假設驗證,不能直接當答案。

- **策略 × 大盤狀態**(每筆平均報酬,95% 信賴區間):

| 策略 | 多頭順風 | 中性 |
|---|---|---|
| 強勢突破 | +2.2% [1.1%, 3.3%],467 筆 | +1.2% [-0.4%, 3.0%],63 筆 |
| 多頭回檔 | +1.3% [0.7%, 2.0%],940 筆 | 不進場 |
| 動能輪動 | +1.0% [-0.7%, 2.7%],245 筆 | +9.4% [4.6%, 15.5%],95 筆(集中在少數幾個月底,有效樣本小) |

  動能輪動在多頭順風時沒有 edge(獲利因子 1.03)。這正是「不同情況用不同模型」要解決的問題。

## 2. 三個原則怎麼落地

### 2.1 順勢而為:大盤濾網保留,出場修好,依情況分配資金

**(a) 先修出場(第 1 到 2 週)**
1. 對每筆歷史交易算 MFE / MAE(持有期間最大浮盈 / 最大浮虧),以及停損出場後 10 天內有沒有漲回進場價以上。這一步用來確認「被洗出場」是不是主因,而不是只看回測數字。
2. 事前寫下假設 H1:「移動停損 3.0 改為 3.5 ATR,且回檔策略的 40 天持有上限改為 60 天,兩段歷史都改善、隨機對照組的百分位也上升。」
3. 用 2.1(a)-1 的證據加上拆段結果決定。通過就改,寫進 `param_changes`;不通過就不改。**一次只改一件事。**

**(b) 「每種情況用最好的模型」:情境分配器**

把每個策略當成一個「模型」。做法:

1. **所有策略永遠在跑**:每個候選策略(含之後的 TQQQ、BTC、均值回歸,以及隨機對照組)每天都在內部模擬帳戶裡跑影子交易,不管有沒有分到錢。這樣才有「它在這種情況下表現如何」的資料,而且不用拿真錢試。
2. **情境只分 6 格**:大盤狀態(多頭順風 / 中性 / 空頭逆風)× 波動(SPY 20 日實現波動高於或低於它過去一年的中位數)。格子太多,每格樣本太少,一定會過擬合。
3. **每格的期望值做收縮**:`估計值 = (n × 該格平均 + 30 × 該策略整體平均) / (n + 30)`。樣本少的格子會被拉回策略的整體平均,不會因為幾筆好運就重壓。
4. **配置規則**:權重和「收縮後期望值減一個標準誤」成正比(約 84% 單邊信賴下緣);下緣小於 0 的策略分 0;單一策略最多 50%;每月調整一次;權重變動小於 10 個百分點就不動,避免來回追。
5. **上線前要過 walk-forward**:每個月只用「那個月以前」的資料算權重,跟固定配比(52/15/22/10)比。**贏過固定配比、而且信賴區間不重疊,才用。** 老實說,一開始只有 3 到 6 個策略,很可能贏不了固定配比。那也是有用的答案:代表現在還不需要分配器。

### 2.2 不斷學習:每筆失敗都留下「症狀」紀錄

**(a) 每筆平倉自動產生一張驗屍卡**(postclose 時自動寫入 `trade_postmortem` 表)

- 事實欄位:進場時的大盤狀態、板塊排名、訊號四層證據、當時的 Muse / Grok 旗標、出場原因、R 倍數、MFE / MAE、持有天數、實際成交與計畫價格的差距。
- **症狀標籤**由程式依固定規則判定,不靠感覺:

| 代碼 | 症狀 | 判定規則 |
|---|---|---|
| S1 | 跳空穿停損 | 停損出場,且出場當天開盤比前一日收盤低至少 1 ATR |
| S2 | 被洗出場 | 停損出場後 10 個交易日內收盤回到進場價以上 |
| S3 | 追高 | 進場價高於 20 日均線超過 2.5 ATR |
| S4 | 大盤翻轉 | 持有期間大盤狀態從多頭順風變成中性或空頭逆風 |
| S5 | 板塊退潮 | 持有期間該板塊掉出領漲前 4 名 |
| S6 | 事件跳空 | 持有期間有一天開盤比前一日收盤低至少 1.5 ATR 且量比 2 倍以上(財報或消息的代理指標;尚未接財報日曆) |
| S7 | 獲利回吐 | MFE 至少 2R,但最後以低於 0.5R 出場 |
| S8 | 執行異常 | 進場或出場成交價偏離當天開盤價超過 0.5% |
| S9 | 消息面 | 持有期間收到該標的的 Muse / Grok ALERT |
| S0 | 正常虧損 | 以上皆非。順勢策略本來就會有,不需要修 |

- 人寫的欄位:一句「我學到什麼」。**可以留空**,但每週至少寫三筆。

**(b) 從症狀到規則改變的管線**(不能跳步)

```
每日:驗屍卡自動產生 -> 每週:統計各症狀的次數與總虧損 -> 某症狀連續兩週排前兩名
-> 寫成假設(「加一條 X 規則,可減少 S? 的虧損,且不傷害其他交易」)
-> 回測 + 隨機對照 + 拆兩段 -> 影子帳戶 4 週 -> 你核准 -> 改規則並記錄
```

- 單一筆失敗**永遠不直接改規則**。一筆虧損通常是雜訊,改規則去躲它是過擬合。
- S0(正常虧損)占比高是健康的。目標不是消滅虧損,是消滅「可以避免的那一類」。

**(c) 每週 AI 覆盤**:Claude 讀一週的驗屍卡、日誌、被擋的訊號(以及它們事後的走勢),產出一份「重複出現的症狀 + 候選假設」清單。只產生假設,不改任何東西。

### 2.3 消息為王:把「推斷」變成可以打分數的紀錄

舊專案的實驗證明:拿新聞情緒預測 1 到 3 天的漲跌沒有用。但你說的「消息」不一樣,是**一步一步推出還沒被定價的結果**。這可以做,前提是每一次推斷都要事先寫下來,之後打分數,不然永遠不知道推斷的能力是真是假。

**事件鏈紀錄 `CHAIN`**(每筆一張):

```
事件(有來源、有時間)
 -> 一階影響(直接受影響的公司或產業)
 -> 二階影響(供應鏈、競爭者、替代品、政策連鎖)
 -> 受影響標的 + 方向 + 時間窗(5 / 20 / 60 天)
 -> 驗證點:什麼數據、什麼日期出現,會證明或推翻這條鏈
 -> 信心(0 到 1)
```

- 來源:Muse、Grok 提供原始事件;推斷可以由 Claude 每天盤後產生,也可以由你手寫。
- **事先寫、事後評**:寫入時間由系統記錄,事後依 5 / 20 / 60 天的實際報酬(扣掉大盤和板塊的部分)自動打分,用 Brier score 檢查信心有沒有校準(說 70% 的事,有沒有大約 70% 發生)。
- **權限階梯**:
  1. 前 3 個月:只記錄、只評分,也可以擋進場(和 Muse 一樣只能降低風險)。
  2. 累積 50 筆以上已評分的鏈、命中率顯著高於隨機基準、信心校準合格後:由你決定是否讓它在風控上限內**微調**部位(例如 ±25%)。這是新的權限,需要你明確修改 `MUSE_BRIDGE.md` 的規則才能開。
  3. 永遠不允許:單靠一條推斷鏈開新倉,繞過順勢濾網。

這樣「消息為王」就從一個信念,變成一個可以被驗證、可以被逐步信任的能力。

### 2.4 穩定:要看的指標和不要追的指標

- **要追**:滾動 3 個月 Sharpe、正報酬月份比例(現行 58%,目標 65% 以上)、最差單月(現行 -10.5%,目標高於 -7%)、最大回撤、每筆期望值的信賴區間下緣。
- **不要直接追勝率**。順勢策略的勝率天生在 40% 左右,硬拉高通常是靠提早停利,結果期望值變低。勝率是結果,不是目標。
- **任何改動的接受條件**:期望值的信賴區間下緣上升,而且最大回撤沒有變大。報酬變高但回撤也變大的改動,不接受。

### 2.6 每週覆盤格式(2026-10-21 起)

每週五的覆盤只用這三段,依序寫,不加其他段落:

1. **事實表**:本週實際與影子的已平倉筆數、每筆期望值與 95% 區間、最大回撤;期權另列同一 setup 的實際對影子差額;被 Muse 擋下的單的反事實 5 / 20 日報酬(`blocked_counterfactual`,依原因分組,同一事件只算一次);驗屍卡症狀前幾名(股票 S 碼、期權 O 碼)。只放數字與來源資料表,不放解讀。
2. **假設**:同時最多 3 條。每條固定寫成「我認為 X,因為 Y;驗證方式 Z;失敗條件 W」。驗證一律走影子或回測,不在 live 上試。
3. **需要你決定的事**:只列要你點頭的項目(放寬規則、擴大部位、切換開關、改排程),每項附上目前的證據與不做的代價。

## 3. Grok:第二個情報員
